DASHBOARD PREVIEW

ABOUT THE PROJECT

Supply chain data into operational insights.

Developed an interactive supply chain analytics dashboard combining customer, shipment and logistics information.

The dashboard analyzes customer activity, orders, shipment performance, freight costs, warehouse operations and satisfaction scores.

Data was transformed using Power Query and analytical measures were created using DAX for KPI-based reporting.

KEY FEATURES

01

Customer Analysis

Analyze customer activity, orders and satisfaction patterns.

02

Shipment Analysis

Evaluate shipment activity and logistics performance.

03

Freight Cost Analysis

Analyze freight costs and shipment-related expenses.

04

KPI Dashboard

Monitor customers, orders, shipment value, freight cost and satisfaction KPIs.
